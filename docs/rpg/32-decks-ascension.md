# Quatre decks pour les Ascensions

**30 cartes par deck**, bicolores, disponibles dans les préconstruits du Duel et du MOBA.
Les huit thèmes existants restent disponibles : le catalogue contient désormais **12 decks**.

L’Ascension indiquée est l’objectif du deck, **pas une carte parmi les 30**. La réserve séparée garde ses sept cartes par défaut. Les recettes lisent les **coûts imprimés** ; une Ascension ne prend ni mana supplémentaire ni invocation normale. Les soutiens ne donnent pas une deuxième invocation normale universelle.

## Choisir un deck

Dans le jeu : **Deck → nom du deck → Jouer avec ce deck**. En MOBA : sélectionner son boîtier, puis **Commencer le duel libre**. Dans la démo locale, le lien **Decks** donne accès à ces vrais menus. Un nouvel invité passe d’abord par son coffret de bienvenue gratuit. Aucun deck personnel n’est remplacé.

### Plan de jeu

1. Poser et conserver le Rōnin, puis réunir l’Onna-musha. Les coûts imprimés ne changent pas avec le Shogun ou les armes.

3. Si un Samouraï est tombé, Réanimation peut le remettre en jeu sans utiliser l’invocation normale. Le sort permet de choisir la créature admissible dans le cimetière.
4. Pour poser Daimyō ou Tojiro depuis la main, sacrifier plutôt un petit soutien que l’autre moitié de la recette. Le Rempart de dunes aide à conserver les matériaux. Les autres Samouraïs, même de coût total 7, ne remplacent pas les deux cartes nommées.

## Vérification et limites

Les quatre listes sont validées en Duel, essai et MOBA : taille de 30, limites de copies, couleurs, cartes auditées et réserve hors-deck. **25 tests dédiés** couvrent les listes et leurs préparations ; huit parcours de règles vont jusqu’à l’Ascension (chaque deck dans chaque mode), avec un quota normal réellement consommé par une pose. Les menus permettent aussi de démarrer une vraie partie avec chacun des quatre préconstruits.

Ce sont des bases cohérentes et testées, pas une promesse de taux de victoire compétitif. Ces listes sont des exemples ; les recettes exigent les cartes nommées, dont la somme des coûts imprimés égale le coût de l’Ascension. Aucun changement de compte, de collection distante ou de base de données n’est effectué.
