# Pixel Runner — Memory

- Le jeu est intégré dans le Vite React existant, sans modifier les quiz ni la messagerie.
- Le rendu est Canvas 2D pour obtenir rapidement un prototype tactile et clavier.
- Le fond généré est chargé depuis `public/pixel-runner-bg.jpg` avec un fallback de dégradés si l’image n’est pas disponible.
- Prochaine évolution possible : classement Supabase, sons déverrouillés au premier geste, skins et défis entre amis.
