# Ambiances optionnelles de la cinématique (V3)

Déposez les fichiers ici avec **exactement** ces noms, puis relancez
`python3 tools/monter-cinematique.py`. Les fichiers absents sont
simplement ignorés (le film reste mixable sans eux).

| Fichier | Usage dans le film | Niveau |
|---|---|---|
| `wind-desert-loop.mp3` | lit de vent sur tout le film (bouclé) | 0.10 |
| `sand-shimmer-loop.mp3` | scintillement de grains, tableau T05 | 0.12 |
| `tea-room-tone.mp3` | pièce feutrée + feu lointain, tableau T10 | 0.10 |
| `deep-drone-loop.mp3` | bourdon grave, portail T11 → titre T12 | 0.13 |
| `bell-hit.wav` (ou `.mp3`) | remplace la cloche synthétique (3 coups) | — |

Conseils : WAV 44,1/48 kHz ou MP3 320, sans écrêtage ; boucles
propres (les fondus d'entrée/sortie de 2 s masquent les raccords).
