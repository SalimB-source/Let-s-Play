🚀 Quitter Vercel — guide simple

Ton site fonctionnera exactement pareil sans Vercel. Tout le code est déjà prêt dans ce dépôt — il te reste juste à brancher ton compte Cloudflare (gratuit).

✅ Gratuit (comme Vercel) ✅ Déploiement auto à chaque git push ✅ Adresse en ….pages.dev ✅ Supabase continue de fonctionner

✅ Check-list (coche au fur et à mesure)

1Compte Cloudflare (gratuit)

  1. Va sur dash.cloudflare.com
  2. Clique sur « Sign up » (en haut à droite)
  3. Crée un compte avec ton email
  4. Valide l'email qu'on t'envoie
💡 Pas besoin de carte bancaire. Pas besoin de nom de domaine.
👉 Si tu as déjà un compte Cloudflare (pour le captcha « Turnstile » à l'inscription), cette étape est déjà faite.

2Connecter ton site

  1. Dans le menu de gauche : Workers & Pages
  2. Bouton « Create application » → onglet « Pages » → « Connect to Git »
  3. Autorise Cloudflare à voir ton GitHub, choisis le dépôt Let-s-Play
  4. Écran « Set up builds and deployments » — remplis exactement comme ça :
ChampValeur
Production branchmain
Build commandnpm run build
Build output directorydist
  1. Clique « Save and Deploy »
  2. Attends 1–2 minutes. Ton site sera en ligne sur une adresse du type : https://let-s-play-xxx.pages.dev (note-la, tu en auras besoin)

3Copier les clés (important)

Ton site a besoin de 3 valeurs. Copie-les depuis Vercel (elles y sont déjà) vers Cloudflare.

🔎 Pour les trouver sur Vercel : vercel.com → ton projet « let-s-play » → Settings → Environment Variables.
➕ Pour les mettre sur Cloudflare : ton projet Pages → Settings → Environment variables → Add variable.

Nom de la variableOù la trouverType sur Cloudflare
VITE_SUPABASE_URL Vercel (ou dashboard Supabase → Settings → API → Project URL) Production + Preview, texte normal
VITE_SUPABASE_PUBLISHABLE_KEY Vercel (ou Supabase → Settings → API → anon/public key) Production + Preview, texte normal
YOUTUBE_API_KEY Vercel (clé API YouTube, commence par AIza) Production + Preview, coche « Encrypt » (secret)
💡 Ne recopie pas VITE_TURNSTILE_SITE_KEY si tu ne t'en sers pas (c'est la protection anti-bot à l'inscription — si tu l'as sur Vercel, copie-la aussi, c'est une 4ᵉ variable).

Clique Save après chaque variable.

4Vérifier que tout marche

Ouvre https://ton-site.pages.dev et teste :

  • La page d'accueil s'affiche
  • Ouvre directement https://ton-site.pages.dev/auth — la page de connexion doit s'afficher (pas une erreur 404)
  • Connecte-toi avec ton compte
  • Le micro/caméra dans un appel vocal/vidéo te demande la permission normalement

5Dire à Supabase la nouvelle adresse

Supabase ne sait pas encore que ton site a déménagé.

  1. Va sur supabase.com → ton projet → Authentication (menu gauche)
  2. URL Configuration
  3. Dans Redirect URLs, ajoute :
https://ton-site.pages.dev/**

(remplace par ta vraie adresse pages.dev)

  1. Save
💡 Si tu as un nom de domaine perso, ajoute-le ici aussi plus tard.

6Supprimer Vercel

Quand les étapes 1–5 sont validées :

  1. Va sur vercel.com → ton projet « let-s-play »
  2. Settings → General → tout en bas : « Delete this project »
  3. Confirme.
🎉 C'est fini. Vercel est débranché, ton site tourne sur Cloudflare.

Et après ?

🔄 Déploiement autoChaque modification poussée sur GitHub (git push) déploie automatiquement le site, comme avant avec Vercel.
👀 Aperçu par PRChaque pull request aura son propre lien de test (aperçu).
🪞 Miroir de secoursGitHub Pages (salimb-source.github.io/Let-s-Play/) continue de tourner en parallèle — tu peux l'ignorer.

SymptômeCauseSolution
